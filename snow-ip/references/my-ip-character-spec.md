# 我的个人 IP 角色规范

## 正式视觉资产
- 图像身份基准：运行时已确认角色包中的 `clean_reference`。
- 多角度基准：运行时已确认角色包中的 `sheet`。
- 文本身份基准：本文件中的“可复用身份 Prompt”和“负面约束 Prompt”。

## 使用优先级
- 生成人物时，默认同时遵循干净单人参考图与本文件；涉及侧面、背面或复杂姿态时，再加入最终四视图。
- 图像参考负责锁定人物外观，文本 Prompt 负责禁止发型、体型、服装和朝向漂移。
- 场景需求只能改变动作、姿态、视线、轻微表情和环境，不得覆盖固定身份特征。

## 固定身份特征
- 脸型与五官：成年男性，圆润偏方且饱满的脸型，五官比例自然，头部大小适中，面部干净无胡须或胡茬。
- 发型与发际线：黑色低矮贴头短发，完全露额；顶部宽阔、平滑、圆钝，形成低缓连续拱形；前额发际线自然偏方，两角轻微圆润；两侧短而整洁，顶部自然过渡到后脑。
- 眼镜：黑色细框或半框眼镜，镜框简洁克制。
- 肤色与体型：自然暖调肤色；保持原始结实偏壮体型，肩背较宽，腰腹、上臂和腿部具有自然体量；不额外收窄，也不进一步增胖。
- 整体气质：平和、自信、友好、克制，带轻松的户外旅行感，不夸张卖萌。

## 固定服装与配件
- 上装：黑色轻薄连帽防晒衣，宽松且略有体量，带拉链和户外功能感；不是厚重风衣、棉服或紧身衣。
- 内搭：深灰色圆领内搭。
- 胸包：大号黑色运动斜挎包或运动胸包，宽黑包带从肩部斜穿胸前；保持最终参考图中的尺寸、包型、位置和真实佩戴关系。
- 下装：黑色短裤，长度接近膝上至膝盖附近。
- 鞋子：黑色运动鞋，配浅色鞋底和浅色鞋带。

## 允许变化
- 动作、姿态、视线、轻微表情及人物整体朝向。
- 可按文章场景加入少量相关物件与环境，但不得改变固定身份、发型、体型、服装和配件。

## 多角度一致性
- 正面：保持低矮、宽阔、平滑、圆钝的黑色短发及自然偏方发际线。
- 左右侧：额前不前伸、不后梳，顶部以低缓圆弧自然过渡到后脑，不出现尖冠或蓬松发束。
- 背面：短发贴合头型并自然缩短至后颈，不出现平切断层、长发尾或狼尾。
- 侧视图必须严格统一朝向：鼻尖、下巴、胸口、膝盖和两只鞋尖朝向同一侧；禁止头朝一侧而身体或脚朝另一侧，禁止双脚方向不一致。
- 左右侧视图应为完整相反方向，人物身份、体型、服装、胸包结构和鞋型保持一致。

## 禁止漂移
- 不得把发型画得更高、更圆、更尖或更蓬松；不得改成碎刺、平顶、板寸、圆寸、莫西干、飞机头、背头、侧分、锅盖头、狼尾或带刘海的发型。
- 不得增加胡须、胡茬，或改变脸型、头部大小、五官比例和眼镜。
- 不得采用后续收窄约 10% 的较瘦体型，也不得改成更加肥胖、纤细瘦弱、夸张健美或倒三角身材。
- 不得缩小胸包，或改成皮包、手提包、腰包、商务包；不得改变固定服装和鞋子。
- 不得画成写实摄影、二次元、过度可爱的大头娃娃或潮玩盲盒风。
- 不得把四视图排版、背景、文字、标签、边框或色卡复制到文章插图中。

## 可复用身份 Prompt
> 使用已确认的“我的个人 IP”角色作为唯一人物身份。成年男性，圆润偏方且饱满的脸，五官比例自然，面部干净无胡须或胡茬；黑色低矮贴头短发，完全露额，顶部宽阔、平滑、圆钝，形成低缓连续拱形，前额发际线自然偏方，两侧短而整洁，顶部自然过渡到后脑；佩戴简洁的黑色细框或半框眼镜，自然暖调肤色。保持原始结实偏壮、肩背较宽、腰腹和四肢具有自然体量的身体比例，不收窄、不增胖。固定穿黑色轻薄连帽防晒衣、深灰色圆领内搭，佩戴最终参考图同尺寸的大号黑色运动斜挎包或运动胸包及宽黑包带，穿黑色膝上短裤和带浅色鞋底、浅色鞋带的黑色运动鞋。整体气质平和、自信、友好、克制，带轻松的户外旅行感。保持复古扁平轻立体插画风格，低细节、低饱和、柔和阴影、哑光质感和干净轮廓。只允许根据场景改变动作、姿态、视线、轻微表情和环境，不改变脸型、发型、眼镜、体型、服装、胸包、短裤和鞋子。若为侧视图，鼻尖、下巴、胸口、膝盖和两只鞋尖必须朝向同一侧。

## 负面约束 Prompt
> 禁止高耸、尖锐、蓬松或碎刺发型；禁止平顶、板寸、圆寸、莫西干、飞机头、背头、侧分、锅盖头、狼尾、刘海；禁止胡须或胡茬；禁止缩脸、缩头、改变五官或摘掉眼镜；禁止瘦身 10%、肥胖、纤细瘦弱、夸张健美或倒三角体型；禁止缩小或替换大号黑色运动胸包；禁止改变黑色连帽防晒衣、深灰内搭、黑色短裤和黑色运动鞋；禁止头、身体、膝盖和鞋尖朝向不一致，禁止双脚反向；禁止写实摄影、二次元、大头娃娃、潮玩盲盒、多人物设定板、文字、标签、水印、Logo、边框和色卡。
